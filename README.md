# SNOWFLAKE-Data-warehousing-concepts
This repository contains a collection of hands-on Snowflake exercises completed while learning cloud data warehousing concepts. The work covers SQL querying, data loading, warehouse management, file staging, semi-structured data, and account usage monitoring

OVERVIEW

I completed this project as part of learning Snowflake and getting more familiar with cloud-based data warehousing. The goal wasn't to build a single end-to-end business project, but rather to work through different exercises that helped me understand how Snowflake works in practice. Throughout the process, I explored how data is loaded, stored, queried, and monitored within the platform while building on the SQL skills I had already developed.

WHAT I DID

As I worked through the exercises, I completed a variety of tasks that introduced me to different areas of Snowflake. I wrote SQL queries to join and analyze data, created and managed virtual warehouses, loaded files using the `COPY INTO` command, and worked with file formats and staged data. I also experimented with data transformations, conditional logic, and semi-structured JSON data. One of the areas I found particularly interesting was exploring warehouse usage and query history because it gave me a better understanding of how Snowflake manages resources behind the scenes. Overall, the project gave me hands-on exposure to many of the tools and features that are commonly used in cloud data environments.

SKILLS USED

Through this project, I developed practical experience with Snowflake, SQL, cloud data warehousing, data loading, file staging, and data transformation. I also gained exposure to concepts such as warehouse management, query monitoring, resource usage tracking, and working with both structured and semi-structured data. More than anything, this project helped me become more comfortable navigating the Snowflake environment and understanding how modern cloud data platforms operate.
